# 硬约束

改代码前先读这一页。每条都对应旧版踩过的坑。

1. **单文件便携**：发布产物是一个 exe，无运行时依赖、无外部 DLL 安装步骤。
2. **数据只写 %LOCALAPPDATA%\input-tip-ng\**：配置、日志、缓存都不写 exe 所在目录。旧版写在 exe 旁边，装到 Program Files 或移动目录后配置与自启一起失效。
3. **单实例**：Local\input-tip-ng-singleton 互斥体；重复启动静默退出，退出码 0，不报错、不弹窗。
4. **永不要求管理员**：常规功能在普通权限下完整可用；需要读提权窗口状态时才另起「提升助手」（P2 再议）。
5. **开机自启只有唯一来源**：计划任务优先、Run 键兜底，两者互斥；每次启动自检，发现漂移/禁用/重复就修复并记日志。
6. **不用 schtasks.exe / PowerShell 建任务**：一律走 Task Scheduler COM。
7. **零第三方依赖优先**：当前仅依赖微软官方 windows crate；引入任何新依赖前先说明理由与体积影响。
8. **DPI**：窗口按 Per-Monitor V2 处理，渲染用设备像素；禁止「预烘焙位图 + 全局缩放比例」的做法（旧版糊的根因）。
   字号配置按「磅」解释（与旧版 AHK 的 s11 一致），内部换算成 DIP 再由 Direct2D 按显示器 DPI 落地。
8a. **扁平化外观**：提示块只用纯色 + 文字，不描边、不加阴影、不用渐变；DDWM 默认描边与系统圆角要显式关掉
   （DWMWA_BORDER_COLOR=none、DWMWA_WINDOW_CORNER_PREFERENCE=DONOTROUND），否则屏幕边缘会出现一圈深色线。
8b. **圆角与尺寸**：圆角半径不得超过高度的 1/4（小尺寸下否则变成胶囊/椭圆）；离屏位图四周各留 1 像素透明边，
   否则抗锯齿会被窗口边界裁成硬边。
8c. **提示窗必须置顶**：WS_EX_TOPMOST + 每次显示 SetWindowPos(HWND_TOPMOST)。缺少置顶时 IsWindowVisible 仍为 true、
   窗口矩形也正确，但会被前台全屏窗口盖住——屏幕上看不见，极难排查。
8d. **caret 要两级取法**：GetGUIThreadInfo 优先；失败时 AttachThreadInput + GetCaretPos（Win11 记事本等控件
   不给 GUITHREADINFO 的 caret 字段）。
9. **界面不写控件背后的说明**：不用「例如……」「勾选后……」这类旁注，靠标题、控件类型、色彩引导。
10. **主题色与图标同源**：一种状态一种颜色，图标、提示牌、设置界面同色值，禁止风格混搭。
11. **中文注释、中文文档**：面向单人维护。
12. **兼容旧配置语义**：映射写在 docs/config-migration.md，改格式必须同步更新该文件。
13. **日志可排障**：失败路径一律写日志（含原因与修复动作），日志自身失败不得影响主流程。
